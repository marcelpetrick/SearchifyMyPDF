# AGENTS.md — working rules for humans and coding agents

This file tells contributors (human or AI) how to work on Searchify PDF.
The product specification is [`VISION.md`](VISION.md); the execution plan and its
status live in [`PLAN.md`](PLAN.md). When they disagree, `VISION.md` wins.

## Ground rules

- **Branch:** work directly on `main`. Keep the tree green; never push a red commit.
- **Commits:** atomic, one logical change each, with a
  [Conventional Commits](https://www.conventionalcommits.org/) message
  (`feat:`, `fix:`, `test:`, `docs:`, `ci:`, `build:`, `refactor:`, `chore:`).
- **Versioning (SemVer):** every commit bumps the version. Use
  `scripts/bump_version.py patch` for ordinary commits and `minor` for major features.
  The version lives only in `src/searchify_pdf/_version.py`. Add a `CHANGELOG.md`
  entry in the same commit (the bump script inserts the heading).
- **Gate:** run `./localPipeline.sh` before each commit. GitHub Actions run the same
  script, so a local pass should predict a CI pass. `scripts/commit.sh` combines
  bump + pipeline + commit + push.
- **License:** GPL-3.0-or-later. Every first-party source file starts with:

  ```python
  # SPDX-License-Identifier: GPL-3.0-or-later
  # Copyright (C) 2026 Marcel Petrick <mail@marcelpetrick.it>
  ```

## Code conventions

- Python ≥ 3.12, `src/` layout, package `searchify_pdf`, CLI `searchify-pdf`.
- Formatting: Black. Linting: Ruff. Types: mypy `--strict`. No competing formatters.
- Business logic must not import Qt. Only `searchify_pdf.ui` may import PySide6.
- External engines are executed with argument arrays, never through a shell.
- User-visible strings go through `searchify_pdf.i18n` (English + German).
  Do not hard-code user-facing text in the processing core; use reason codes.
- Originals are never modified. Outputs are staged in the destination directory,
  validated, and only then published (see `docs/adr/0004-output-publication.md`).

## Tests

- `tests/unit` — pure logic, fast, no OCR engine.
- `tests/integration` — real OCR via OCRmyPDF/Tesseract on synthetic fixtures
  (marker `ocr`).
- `tests/ui` — Qt widgets offscreen through pytest-qt (marker `ui`).
- `tests/e2e` — runs the packaged artifact in a clean container (marker `e2e`).
- Coverage: statement **and** branch coverage are checked separately;
  hard minimum 95 % each (target 98 %). See `scripts/check_coverage.py`.
- Fixtures are synthetic (generated by `tests/fixtures.py`) or permissively
  licensed (`tests/fixtures/real/SOURCES.md`). Never commit personal documents.
